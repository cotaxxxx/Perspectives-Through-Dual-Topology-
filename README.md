# Perspectives Through Dual Topology

## 双対位相によるものの見方

幾何学と小説という異なる領域を、共通の観測手続きから比較する研究です。

- **幾何双対位相**：内部基点からの動径と境界法線の関係を測り、停留点・対称性・分岐を観測する。
- **小説双対位相（Novel Dual Topology）**：記録と経験、構造と意味、到達と伝達などの配置間を移動し、保存される事実・変化する意味・未解決を分離する。
