# Perspectives Through Dual Topology

## 双対位相によるものの見方

確定事項、解釈、行動、未解決を混同しないための研究体系です。

- **総論**：領域共通の観測・記録・判断規律。
- **各論：小説双対位相**：本文における観測事実・解釈候補・行動・空所。
- **各論：幾何双対位相**：錐体積加重動径・法線角汎関数の停留点・対称性・分岐。
